PZ_Optimization
Полная инструкция по установке

Мод для оптимизации фрейм-тайма и стриминга чанков. Работает на Windows, Linux и macOS.

1
Скачайте и включите моды
Steam Workshop

Подпишитесь на все элементы из коллекции и активируйте мод в главном меню игры:

  • Коллекция модов (Steam Workshop)
  • PZ_Optimization — страница мода (Steam Workshop)
  • Дополнительные файлы для папки mods (Google Drive)

Файлы с Google Drive распакуйте в папку mods по пути user/zomboid/mods.

2
Запустите установочный скрипт
PowerShell (Windows) или curl (Linux)

Откройте терминал и выполните команду для вашей операционной системы.

🪟 Windows — откройте PowerShell от имени администратора:

PowerShell 
irm https://github.com/xD3I/PZ_Optimization/releases/latest/download/install.ps1 | iex

🐧 Linux — откройте терминал:

Bash 
curl -fsSL https://github.com/xD3I/PZ_Optimization/releases/latest/download/install.sh | bash
3
Настройте мод в игре
Меню Options → PZ_Optimization

После установки перезапустите игру и выполните следующие действия:

  1. Зайдите в Настройки (Options).
  2. Найдите раздел PZ_Optimization.
  3. Нажмите кнопку «Enable All» — это включит все оптимизации.

В разделе «Enchantment» (графика) можно дополнительно настроить визуальные параметры под ваше железо.

4
Настройка оперативной памяти
Для систем с 16+ ГБ ОЗУ

Если у вас много оперативной памяти, можно увеличить лимит для Java-машины игры.

Перейдите в папку с игрой. По умолчанию:

Путь 
D:\SteamLibrary\steamapps\common\ProjectZomboid

Найдите файл ProjectZomboid64.json и откройте его в блокноте. Замените значение параметра -Xmx на рекомендуемое:

Объём ОЗУ Значение -Xmx
16 ГБ -Xmx6144m
32 ГБ и более -Xmx8192m
JSON (фрагмент) 
"-Xmx6144m",

Инструкция составлена на основе официального описания мода PZ_Optimization.
